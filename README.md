# 찐알렉스 피하기

실제 학교를 본뜬 맵에서 친구들과 하는 3D 1인칭 술래잡기 웹 게임.
배포 주소: https://88swjung.github.io/alex_sshs/

## 1단계: 학교 한 층 맵 + 1인칭 이동

혼자 걸어 다닐 수 있는 단계입니다. (술래잡기·멀티플레이·숨기·문 잠그기·밤 모드는 이후 단계)

- 임시 학교 1층: 복도(60m) + 교실 6개 + 화장실 2개 + 자습실 + 교무실 + 양 끝 계단실
- 맵 구조는 `js/mapData.js` 에만 들어 있어서, 이 파일을 바꾸면 실제 학교 배치도로 교체할 수 있음
- 조작: 화면 클릭 → 시작 / `WASD` 이동 / 마우스 시점 / `Shift` 달리기 / 마우스 오른쪽 버튼 조용히 걷기 / `ESC` 일시정지
- 벽·가구 충돌, 벽을 따라 미끄러지는 이동, HUD(이동 상태, 좌표, 현재 방)

## 그래픽 · 화면 디자인

- 형광등 아래의 평범한 고등학교 분위기: 채도를 낮춘 벽·바닥, 회색 몰딩, 알루미늄 창틀, 실명 표지판
- 교실: 앞벽에 화이트보드 + 가운데 전자칠판(둘 다 빈 상태), 1인용 책상·의자(파란 플라스틱 서랍·좌판), 교탁
- 그림자 맵 없이 가짜 그늘로 입체감: 벽/가구 아래 어둠, 벽 아래 그늘 띠, 가구 밑 그림자, 형광등 빛 얼룩
- 창문·게시판·포스터·소화기·휴지통은 **벽 구조를 보고 자동으로** 놓임 (mapData 만 바꾸면 따라 바뀜)
- 맵: 복도 서쪽 끝을 자습실이 막고(문이 복도 끝에 있음), 그 앞 복도 북쪽 옆에 계단실, 동쪽 끝에 계단실.
  원래 자습실 자리는 `kind: 'solid'` 방(드나들 수 없는 벽으로 막힌 공간)으로 막음
- HUD: 현재 방, 미니맵(mapData 에서 자동 생성), 이동 상태, 조작 안내, 좌표
- 성능: 그리기 호출 약 15번(상자를 InstancedMesh 로 묶음), 프레임이 떨어지면 해상도를 자동으로 낮춤
- 연출: 걸을 때 화면 흔들림, 달릴 때 시야각 확대 (`js/config.js` 의 `VIEW` 에서 끌 수 있음)

## 로컬 실행

빌드 과정이 없는 정적 페이지입니다. 이 폴더에서 웹 서버만 띄우면 됩니다.

```bash
python -m http.server 8000
```

브라우저에서 http://localhost:8000/ 을 엽니다. (`index.html` 을 더블클릭해서 열면 모듈 로딩이 막혀 동작하지 않음)
Three.js 는 CDN 에서 불러오므로 인터넷 연결이 필요합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 뼈대, Three.js import map, 시작 화면, HUD |
| `css/style.css` | 화면 스타일 |
| `js/main.js` | 시작, 포인터 잠금, HUD 갱신, 그리기 반복 |
| `js/config.js` | 속도·감도·눈높이, 색상·벽 페인트·바닥 스타일, 화면 연출/성능 설정 |
| `js/mapData.js` | 맵 구조 데이터 (방, 문, 시작 위치) |
| `js/mapBuilder.js` | mapData → 바닥·벽·천장·문·표지판 생성, 가구 배치, 충돌 정보 생성 |
| `js/furniture.js` | 가구 종류(상자 조합)와 방 종류별 자동 배치 |
| `js/decor.js` | 벽 면을 보고 창문·게시판·포스터·소화기·휴지통 자동 배치 |
| `js/graphics.js` | 재질(가짜 그늘 셰이더), 조명, 안개, 자동 해상도 조절 |
| `js/textures.js` | 코드로 그리는 텍스처 (그림자 얼룩, 표지판) |
| `js/minimap.js` | 미니맵 (mapData 에서 자동 생성) |
| `js/player.js` | 1인칭 시점, 이동, 충돌, 화면 흔들림 |
