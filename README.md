# 찐알렉스 피하기

실제 학교를 본뜬 맵에서 친구들과 하는 3D 1인칭 술래잡기 웹 게임.
배포 주소: https://88swjung.github.io/alex_sshs/

## 1단계: 학교 한 층 맵 + 1인칭 이동

혼자 걸어 다닐 수 있는 단계입니다. (술래잡기·멀티플레이·숨기·문 잠그기·밤 모드는 이후 단계)

- 맵: 실제 학교 **예지관 3층** (길이 약 95m). 참고 그림 `school_structure/예지관/3F/예지_3F_general.png` 을 그대로 옮김
  - 위쪽 줄: 첨단물리 기기실, 물리실험실2·3, 교무실, 물리강의실2, 여자화장실, 계단, 남자화장실
  - 아래쪽 줄: 물리실험실1, 물리준비실, 교무실, 물리강의실1, 생활안전부, 상담실, 협의실
  - 가운데 복도(폭 3m): 서쪽 끝 "외부연결"에서 시작, 동쪽 끝은 체육관(벽으로 나뉘고 여닫이문 1개), 체육관 동쪽에 "융합인재관 연결"
  - 계단: 가운데 올라가는 계단 + 양옆 내려가는 계단 (몇 칸만 만들고 막아 둠), 외부연결·융합인재관 연결도 문 없이 뚫린 짧은 통로(끝은 막아 둠)
  - 방 안은 `school_structure/예지관/3F/예지_3F_inside.png` 그림대로 채움 (아래 "방 내부" 참고)
- 문: 여닫이(`swing`)와 미닫이(`sliding`)를 `world.doors[].kind` 에 기록. 콘솔에서 `game.world.setDoorOpen('gym-door', false)` / `toggleDoor(id)` 로 열고 닫을 수 있음 (닫으면 못 지나감)
- 맵 구조는 `js/mapData.js` 에만 들어 있어서, 이 파일을 바꾸면 실제 학교 배치도로 교체할 수 있음
- 조작: 화면 클릭 → 시작 / `WASD` 이동 / 마우스 시점 / `Shift` 달리기 / 마우스 오른쪽 버튼 조용히 걷기 / `ESC` 일시정지
- 벽·가구 충돌, 벽을 따라 미끄러지는 이동, HUD(이동 상태, 좌표, 현재 방)

## 방 내부 (예지_3F_inside.png)

- 물리강의실 1·2: 학생은 동쪽(앞)을 보고 앉는 1인용 책상·의자, 동쪽 벽 화이트보드 + 가운데 전자칠판, 긴 교탁 + 의자, 복도 쪽·창가 긴 책상
- 물리실험실 1·2·3: 실험대(+의자 4개)가 줄지어 놓이고, 긴 교탁·칠판(실험실 2·3), 책장·장·높은 장·높은 실험장
- 물리준비실: 북쪽 장 2개, 책상 2개, 남쪽 벽에서 뻗은 실험장 4줄 / 첨단물리 기기실: 실험대 4개 / 교무실 2곳: 책상 4개
- 남자화장실: 변기 칸 3개(칸막이) + 소변기 4개(가림판) + 세면대, 여자화장실: 칸 4개 + 세면대
- 방 사이 문(여닫이): 물리실험실1↔물리준비실, 물리준비실↔교무실(남), 물리실험실2↔물리실험실3
- 체육관: 마룻바닥(코트 선, 벽걸이 골대) + 단상(높이 0.5m, 앞면은 막혀 있고 양쪽 끝 계단으로만 오름, 피아노) + 단상 위아래 방 2개 + 좁은 통로(동쪽 벽을 따라 한 바퀴)
  - 그림에서 애매했던 곳: 긴 빨간 선은 체육관 마룻바닥과 단상 쪽의 경계(벽 없이 터짐), 단상 위 작은 네모는 피아노, 둥근 모서리는 직각으로 처리, 이름 없는 "무슨방"은 창고형 방
- 그림에 없는 방(여자화장실, 생활안전부, 상담실, 협의실)은 실제 고등학교처럼 채움

## 창문 · 햇빛

- 모든 방·복도의 건물 바깥쪽 벽에 십자 창살 없는 통유리 창문이 자동으로 달림
- 창문마다 바닥에 햇빛 얼룩과 창에서 비스듬히 내려오는 옅은 빛줄기
- 검은 커튼은 그림의 물결선 자리에만: `curtains: ['N']` (그 쪽 벽 창문, 걷어 둔 상태), 문의 `curtain: true` (문 유리창)

## 그래픽 · 화면 디자인

- 형광등 아래의 평범한 고등학교 분위기: 채도를 낮춘 벽·바닥, 회색 몰딩, 알루미늄 창틀, 실명 표지판
- 교실: 앞벽에 화이트보드 + 가운데 전자칠판(둘 다 빈 상태), 1인용 책상·의자(파란 플라스틱 서랍·좌판), 교탁
- 가구는 모두 `world.furniture` 에 id·종류가 기록됨 (숨기·물건 찾기용)
- 그림자 맵 없이 가짜 그늘로 입체감: 벽/가구 아래 어둠, 벽 아래 그늘 띠, 가구 밑 그림자, 형광등 빛 얼룩
- 창문·게시판·포스터·소화기·휴지통은 **벽 구조를 보고 자동으로** 놓임 (mapData 만 바꾸면 따라 바뀜)
- 방 안 가구는 `mapData.js` 의 방마다 `items` 로 적음: `{ type, x, z, face }` 또는 벽에 붙이는 `{ type, wall, at }`
- HUD: 현재 방, 미니맵(mapData 에서 자동 생성), 이동 상태, 조작 안내, 좌표
- 성능: 그리기 호출 약 15번(상자를 InstancedMesh 로 묶음), 프레임이 떨어지면 해상도를 자동으로 낮춤
- 연출: 걸을 때 화면 흔들림, 달릴 때 시야각 확대 (`js/config.js` 의 `VIEW` 에서 끌 수 있음)

## 로컬 실행

빌드 과정이 없는 정적 페이지입니다. 이 폴더에서 웹 서버만 띄우면 됩니다.

```bash
python -m http.server 8000
```

브라우저에서 http://localhost:8000/ 을 엽니다. (`index.html` 을 더블클릭해서 열면 모듈 로딩이 막혀 동작하지 않음)
Three.js 는 CDN 에서 불러오므로 인터넷 연결이 필요합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 뼈대, Three.js import map, 시작 화면, HUD |
| `css/style.css` | 화면 스타일 |
| `js/main.js` | 시작, 포인터 잠금, HUD 갱신, 그리기 반복 |
| `js/config.js` | 속도·감도·눈높이, 색상·벽 페인트·바닥 스타일, 화면 연출/성능 설정 |
| `js/mapData.js` | 맵 구조 데이터 (방, 방 안 가구 `items`, 문, 뚫린 통로, 계단, 단상, 시작 위치) |
| `js/mapBuilder.js` | mapData → 바닥(단상 높이 포함)·벽·천장·문(문짝·문 유리창·커튼 열고 닫기)·표지판 생성, 가구 배치, 충돌·바닥 높이(`world.groundAt`) 계산 |
| `js/furniture.js` | 가구 종류(상자 조합)와 방 종류별 자동 배치 |
| `js/decor.js` | 벽 면을 보고 통유리 창문(+햇빛, 검은 커튼)·게시판·포스터·소화기·휴지통 자동 배치 |
| `js/graphics.js` | 재질(가짜 그늘 셰이더), 조명, 안개, 자동 해상도 조절 |
| `js/textures.js` | 코드로 그리는 텍스처 (그림자 얼룩, 표지판) |
| `js/minimap.js` | 미니맵 (mapData 에서 자동 생성) |
| `js/player.js` | 1인칭 시점, 이동, 충돌, 화면 흔들림 |
